# isometric-integrated
This Godot plugin integrates into Godot's builtin rendering engine in order to
render isometric pixel art in 3D space. This allows lighting, shadows, and depth
occlusion to work out of the box without resorting to y-sorting and other 2D
solutions. 

The tradeoff is, each isometric object must be associated with a mesh to render
the 3d information correctly.

## Getting Started

As with any godot plugin, all that's needed to begin using Isometric Integrated
is to download this code, and add the isometric-integrated folder (found in the 
addons) folder of this repository) into the addons folder of your own project.

For an explanation of the plugin's functionality and its creation, see 
[my blog](https://radiance-creative.com/blog/) or check the documentation
within the plugin. Most functionality should be pretty intuitive to use.g
